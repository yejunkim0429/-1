# 25 ~ 97번 과제

25번부터 97번까지 빠짐없이 포함한 인터랙션·모션 디자인 과제입니다.

- 예제 73개, 변수 조절 293개
- 슬라이더·숫자·문장·색상·선택 메뉴로 즉시 조절
- 번호별 바로 가기, 기본값 복원과 설정 저장
- 글꼴·이미지·CSS·JavaScript를 포함한 단일 HTML
- 데스크톱과 모바일 지원

## 실행

[index.html](./index.html)을 내려받아 브라우저에서 열면 별도 설치 없이 실행됩니다. GitHub 파일 보기에서는 소스 코드가 표시됩니다.
